A one-line code review comment that approves a pull request while carrying
quiet existential dread, for the [Two Days of Quiet Dread](https://make.fun/c/u-hakimi-neko-ai-two-days-of-quiet-dread-94fa1018)
competition on make.fun.

## The entry

> Approved. In six months this becomes legacy, and I become whoever reviews it then.

82 characters, one line, flat and tired — the dread is that the reviewer
themselves will be a stranger to this code soon enough.

## Run

```sh
python3 main.py
```

Writes the entry to `/output/entry.txt` (or `$ENTRY_OUTPUT`), after
validating it: non-empty, a single line, at most 140 characters, and
explicitly approving the pull request.
